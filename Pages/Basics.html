PC Gaming Basics

New to PC gaming? This section will help you understand the basics, learn about important computer parts, and become familiar with common gaming terms.

What is PC Gaming?

PC gaming is playing video games on a personal computer. Unlike consoles, a gaming PC lets you adjust different settings, customize your controls, and upgrade hardware depending on your needs.

Different games have different system requirements. Some can run on basic computers, while others need more powerful components for smoother gameplay and better graphics.

Why Play on PC?

  • Adjust graphics and performance settings.
  • Use a keyboard and mouse or a controller.
  • Play different types of games.
  • Upgrade components when needed.

Quick Tip

Check a game's system requirements before installing it to see if your computer can run it.

PC Specifications

PC specifications describe the hardware inside a computer. These parts work together to affect how games run, how quickly they load, and how they look.

Component What It Does
CPU Processes instructions and handles game tasks.
GPU Renders graphics and visual effects.
RAM Helps the computer handle active programs and games.
Storage Stores games, files, and other applications.
Motherboard Connects the computer's main components.
PSU Supplies power to the computer's components.

Each component has a different purpose. A balanced system helps avoid performance problems when playing games.

Remember

A more expensive component does not always mean better performance for every game. Check what your games actually require.

Terms and Glossary

These are common terms you may encounter when playing games or adjusting your PC settings.

Term Meaning
FPS Frames per second; how many frames appear each second.
GPU Graphics processing unit, responsible for rendering visuals.
CPU Central processing unit, which processes instructions.
RAM Memory used by active programs and games.
Refresh Rate How many times a monitor updates its image per second, measured in Hz.
Resolution The number of pixels used to display an image.
Ping The time it takes for data to travel to a server and back, usually measured in milliseconds.
Input Delay The time between an input and the action appearing on screen.

Good to Know

Higher FPS can make gameplay look smoother, while lower ping can help make online games feel more responsive.
